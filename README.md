# Coleção de Templates de Landing Pages de Alta Conversão

Repositório contendo modelos modulares, leves e focados em alta taxa de conversão para tráfego pago e orgânico em diferentes nichos.

## 📁 Modelos Disponíveis

- **`lp-clinica-estetica/`**: Template voltado para clínicas médicas de estética, dermatologia e harmonização facial.
  - Foco em conversão direta para WhatsApp.
  - Carregamento rápido sem dependências pesadas.
  - Prova social, autoridade e quebra de objeções integradas.
